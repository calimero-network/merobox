For the protocol terms these build on, see the
[Calimero Core docs](https://calimero-network.github.io/core/). v1's names map
to release-v2 as namespace = organization, group = team, context = app
instance, application = signed package.

| Term | Definition |
| --- | --- |
| **account** | A person on the cluster, signed in with a passkey. A workflow's `accounts` are signed up before its first step; `{{accounts.<name>.account_id}}` is one's id. A v1 node ports to an account. |
| **API key** | A scoped credential an account creates (`create_api_key`); a step can act with `api_key` instead of `account`. |
| **app** | A deployed WASM application (`deploy`), replicated by its own Raft log. v1's context. |
| **cloud-v2** | merobox's release-v2 backend, selected by `backend: cloud-v2` in a workflow. |
| **not applicable** | A ported workflow that no longer tests what its v1 original did, marked `not_applicable: <reason>`; never run, never a pass (`merobox cloud run` exits 3). |
| **ops token** | The cluster's operator token, `{{ops_token}}`, for the `ops` step. |
| **organization** | Accounts that share apps (`create_org`, `invite`, `redeem_invite`). v1's namespace. |
| **package** | A signed `.mpk` release, installed by name from the cluster's registry (`install_package`) and deployed or upgraded by version. |
| **port** | `merobox cloud port`: converts a v1 workflow to a cloud-v2 one. |
| **ProcessCluster** | The cluster merobox starts: one `merod` process per node on 127.0.0.1 (`merobox/cloud_v2/cluster.py`). |
| **step** | One entry in a workflow's `steps`, with a `type` from `STEP_TYPES`. |
| **team** | A subgroup of an organization (`create_team`, `team_*`). v1's group. |
| **workflow** | A YAML file of a cluster, accounts and steps, run by `merobox cloud run`. |

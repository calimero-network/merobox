## From pytest

`merobox.cloud_v2` is importable:

```python
from merobox.cloud_v2 import ProcessCluster, run_workflow, run_workflow_outcome

def test_failover():
    assert run_workflow("workflows/failover.yml")          # True only on "passed"

def test_my_own_client():
    cluster = ProcessCluster(nodes=3, base_port=2900)       # merod from MEROD_BINARY
    cluster.start()
    try:
        url = cluster.url(1)                                # http://127.0.0.1:2901/
        ...                                                 # drive it with CloudClient
        cluster.kill_node(2)
    finally:
        cluster.stop()
```

`run_workflow_outcome` answers `"passed"`, `"failed"` or `"not_applicable"`.
`tests/test_cloud_v2_integration.py` runs every shipped example this way when
`MEROD_BINARY` and `KV_STORE_WASM` are set.

## merobox's own checks

```bash
pip install -r requirements.txt && pip install -e .
make format-check                      # black --check and ruff, as CI's format job
python -m pytest merobox/tests/unit    # as CI's test-unit job
```

The unit tests mock `calimero_client_py` (`merobox/tests/conftest.py`), so they
need no node. CI's `test-cloud-v2` job runs the examples against core's
`release-v2` branch; see [Examples](/workflows/examples/) for the inputs.
